# 俄罗斯方块 (Tetris)

纯 HTML/CSS/JS 实现的经典俄罗斯方块游戏，无需任何依赖。

## 玩法

- **← →** - 左右移动
- **↑** - 旋转
- **↓** - 软降（加速下落）
- **空格** - 硬降（直接落底）
- **P** - 暂停

也支持移动端触屏操作。

## 特性

- 幽灵块预览（显示落点位置）
- 下一个方块预览
- 等级系统（每消10行升一级，速度递增）
- 分数计算（消行越多得分越高）
- 响应式设计，支持手机/平板/桌面
- 暗色主题 + 霓虹风格
